Job
Exactly what to build. The job runs with the chat model, using knowledge base retrieval plus the model's own knowledge.
Stages as ## title lines, sub-stages as - item lines, an optional check command after ::. This is the validation list: an item is checked off only after its check passes, a stage is complete only when all its sub-stages are checked off. The model cannot add, remove, reorder, or reword items — it can only check them off, through the validation gate.
Sent as the system prompt on every model call for this job, ahead of the description and checklist, so the agent follows it throughout the build.
When the agent reports the build done, the system verifies everything independently — it does not take the agent's word. Every check command and every test in the job's output directory is re-run. Each stage and sub-stage shows pass/fail with the command run and its output, and any item the agent marked ready that fails verification is flagged. The job is marked complete only when every item passes and all tests come back clean; otherwise it is marked failed, with the failing items listed.
